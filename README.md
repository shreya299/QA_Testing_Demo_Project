# QA Banking Application – Manual & API Testing Project

This project simulates QA activities for a Retail Banking Web Portal, inspired by real QA workflows performed in enterprise environments such as Cognizant.  
It showcases hands-on experience in manual UI testing, test case design, defect management, API validation using Postman, and documentation workflows using SharePoint and Azure DevOps.

---

## Project Overview

This QA project covers validation of critical online banking features including:

- User Login and Authentication  
- Account Summary Retrieval  
- Fund Transfer Between Accounts  
- Error Handling (e.g., insufficient balance, invalid inputs)  
- API request and response validation using Postman  

The goal is to replicate a realistic corporate QA workflow with clean documentation and structured test evidence.
